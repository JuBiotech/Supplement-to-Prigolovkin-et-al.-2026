This repository contains the data and manuscript figures of *Catching the Bandit: Contextual Bayesian Optimization of Lysostaphin secreting Corynebacterium glutamicum* (2026), L. Prigolovkin, M. Osthege, J. Sander, M. Siska, W. Wiechert, C.U. Riedel, M. Oldiges.

# Contents
- `/data` contains the raw experimental data
- `/manuscript` includes the manuscript figures and additional supporting figures not part of the manuscript
